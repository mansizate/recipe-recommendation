# 🍲 Recipe Recommendation System

A simple web-based **Recipe Recommendation System** that helps users explore and find recipes easily.

## ✨ Features

- 🍴 Browse different recipes
- 🔍 Search and explore recipes
- 👤 User Sign Up & Login
- 📝 Manage recipe information
- 🗄️ MySQL database integration
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Tools:** XAMPP, Git, GitHub

## 🚀 How to Run

1. Download or clone the repository.
2. Put the project inside `xampp/htdocs/`.
3. Start **Apache** and **MySQL** in XAMPP.
4. Create/import the required database in **phpMyAdmin**.
5. Open the project in your browser:

```text
http://localhost/reciperecommandation/
```
